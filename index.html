Conecta este dispositivo

Tus datos se guardan en un repositorio privado de GitHub, no en esta página. Indica cuál es y pega un token con permiso de escritura. Se quedan solo en este dispositivo: no se envían a ningún otro sitio.

El privado donde viven los datos, por ejemplo ValitoLerio/datos
Se guarda en este navegador. Si es un dispositivo prestado, desconéctate al terminar.
¿Cómo creo el token?
  1. Entra en github.com/settings/personal-access-tokens/new
  2. Elige un token fine-grained y ponle un nombre y una caducidad
  3. En Repository access, marca Only select repositories y elige solo tu repositorio de datos
  4. En Permissions → Repository permissions, pon Contents: Read and write
  5. Genera el token, cópialo y pégalo aquí. GitHub solo te lo enseña una vez

Cómo funciona esto

Los datos van y vienen solos

Cada cambio se sube a tu repositorio privado un par de segundos después. Abre la misma web en otro dispositivo y encontrarás lo último que guardaste.

Esta página es pública

El código de las apps lo puede ver cualquiera, y por eso no contiene ningún dato tuyo. Lo privado son los datos, que viven en el otro repositorio.

Si cambias de dispositivo

Cada uno necesita su propia conexión. Al desconectar se borran el token y los datos de este navegador, pero no los del repositorio.
